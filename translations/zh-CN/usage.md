# 在终端中使用 Pi

在希望处理的目录中运行 `pi`。Pi 使用该目录发现文件、指令与配置，并对保存的会话分组。如果尚未安装 Pi 或选择模型，请先按照[快速入门](quickstart.md)操作。

Pi 可能会在加载项目资源之前，询问你是否信任工作目录，参阅[项目信任](security.md#understand-project-trust)。

<p align="center"><img src="images/interactive-mode.png" alt="Pi 交互模式，显示对话、编辑器和状态信息" width="750"></p>

对话记录展示你的提示、Pi 的响应、工具调用、结果和错误。你在编辑器中输入提示与命令。底栏显示当前目录、会话、模型、上下文使用量，以及累计用量和费用。

## 输入提示

输入请求并按 `Enter` 发送。使用 `Shift+Enter` 换行，或按 `Ctrl+G`，在已配置的外部编辑器中编写较长的提示。

要加入文件或图像：

- 输入 `@` 搜索文件，并将其添加到提示中。
- 按 `Tab` 补全路径。
- 粘贴图像，或将其拖入兼容的终端。

## 跟踪 Pi 的工作

Pi 工作时会展示每次工具调用及结果。按 `Ctrl+O` 展开或折叠工具输出，按 `Ctrl+T` 显示或隐藏思考内容。

启动标题区域列出 Pi 已加载的指令和资源。编辑器边框指示当前思考级别。模型使用上下文时，底栏会随之更新并报告用量。

Pi 不会在每次工具调用前都征求许可。请检查命令与修改后的文件，并为不可信内容或无人值守工作使用沙箱，参阅[安全](security.md)。

## 调整方向

Pi 工作期间，你可以继续输入：

| 你的意图 | 操作 |
|---|---|
| 调整当前任务 | 输入消息并按 `Enter` |
| 在当前任务之后添加工作 | 输入消息并按 `Alt+Enter` |
| 将排队消息放回编辑器 | 按 `Alt+Up` |
| 停止当前任务 | 按 `Escape` |

通过 `Enter` 发送的消息会等待当前响应及其工具调用完成，然后引导下一次响应。通过 `Alt+Enter` 发送的后续消息，会等待 Pi 完成当前任务。中止运行会将排队消息放回编辑器。

Windows Terminal 保留了部分 Alt 快捷键。Windows 上的替代方式请参阅[终端配置](terminal-setup.md)。

## 切换模型或设置

输入 `/` 搜索可用命令。最常用的命令包括：

- `/model` 选择模型，按 `Ctrl+L` 也能打开同一个选择器。
- `/thinking` 选择当前模型使用的推理强度，按 `Shift+Tab` 循环切换受支持的级别。
- `/login` 和 `/logout` 管理提供商访问。
- `/settings` 修改常用偏好。

提示模板、技能和扩展可以向同一菜单添加更多命令。参阅[选择模型](models.md)、[配置](configuration.md)，或完整的[斜杠命令参考](slash-commands.md)。

## 继续工作或重新开始

除非禁用会话持久化，否则 Pi 会自动保存会话。

- `/new` 开始新会话。
- `/resume` 打开另一个已保存会话。
- `/name` 为当前会话设置便于辨识的名称。
- `/session` 显示其文件、ID、消息数量、token 用量和费用。

希望在保留现有工作的同时探索其他方案时，使用 `/tree`、`/fork` 或 `/clone`。使用 `/compact` 减少发送给模型的对话历史。相关工作流请参阅[会话与上下文](sessions.md)。

退出 Pi 后，在同一目录运行 `pi --continue`，即可恢复该目录最近的会话。

## 运行终端命令

在命令前加上 `!`，即可运行命令，并将输出加入对话：

```text
!git status
```

如果希望运行命令但不将输出发送给模型，使用 `!!`。

## 复制、导出或分享结果

按 `Ctrl+X` 或运行 `/copy`，复制助手最后一次响应。使用 `/export` 将会话保存为 HTML 或 JSONL。

使用 `/share` 上传会话并获取查看链接。默认情况下，如果已进行 Radius 身份验证，产物对你的 Radius 组织可见；否则，Pi 通过 GitHub CLI 创建私密 GitHub gist。[`sessionShareDestination`](settings.md#sessions-and-context) 设置可以强制选择任一目标。分享前应先检查会话，因为其中可能包含提示、工具输出、文件内容，以及对话中暴露的凭据。

## 调整终端

默认的全屏模式会固定编辑器和状态区域，让对话记录在终端窗口内滚动。常规模式则使用终端正常的回滚缓冲区。可以通过 `/settings` 或 `--tui-mode` 选择模式。

不同终端对鼠标输入、键盘快捷键和内联图像的支持有所不同。平台相关配置请参阅[终端配置](terminal-setup.md)，全部可配置快捷键请参阅[按键绑定](keybindings.md)。运行 `/hotkeys`，查看当前会话中生效的快捷键。

## 收集诊断信息

排查终端渲染或对话状态问题时，运行 `/debug`。Pi 将渲染后的终端行和当前会话消息写入[智能体目录](configuration.md#agent-directory)中的 `pi-debug.log`。

分享前请检查该文件。它可能包含提示、模型响应、工具输出、文件内容和终端数据。
