# 斜杠命令

在 Pi 的终端编辑器中输入 `/`，即可搜索当前会话可用的命令。本页列出当前 Pi 版本的内置命令。

扩展、提示模板和技能都能添加命令，因此 Pi 中的命令菜单才是当前会话所加载资源的准确参考。

## 模型与设置

| 命令 | 说明 |
|---|---|
| `/settings` | 打开设置 |
| `/model [provider/model]` | 选择模型 |
| `/thinking [level]` | 设置思考级别 |
| `/scoped-models` | 配置交互循环切换使用的模型 |
| `/login [provider]` | 添加提供商身份验证 |
| `/logout` | 移除提供商身份验证 |
| `/llama` | 管理所配置 llama.cpp 路由器上的模型 |

## 会话与上下文

| 命令 | 说明 |
|---|---|
| `/new` | 开始新会话 |
| `/resume` | 切换到另一个已保存会话 |
| `/name [name]` | 设置会话显示名称；省略名称时显示当前名称 |
| `/session` | 显示当前会话信息与统计 |
| `/tree` | 浏览会话树 |
| `/fork` | 从较早的用户消息创建新会话 |
| `/clone` | 在当前位置复制当前会话 |
| `/compact [instructions]` | 压缩当前上下文，可选提供自定义指令 |
| `/import <path>` | 导入并恢复 JSONL 会话 |

## 导出与分享

| 命令 | 说明 |
|---|---|
| `/copy` | 复制助手的上一条消息 |
| `/export [path]` | 将会话导出为 HTML 或 JSONL |
| `/share` | 上传会话并返回查看链接 |
| `/bug [description]` | 为 Pi 开发者准备私有错误报告 |

导出或分享会话前，请先检查内容。会话可能包含提示、工具参数、命令输出、文件内容，以及对话中暴露的凭据。

## 运行时与项目

| 命令 | 说明 |
|---|---|
| `/trust` | 保存项目信任决定，供未来 Pi 进程使用 |
| `/mcp` | 管理 MCP 服务器：登录、重连、启用或禁用，以及更改暴露方式 |
| `/reload` | 重新加载快捷键、扩展、技能、模板、主题和上下文文件 |
| `/hotkeys` | 显示当前生效的键盘快捷键 |
| `/changelog` | 显示变更日志条目 |
| `/quit` | 退出 Pi |

## 资源添加的命令

- 扩展可以注册带有自身参数和补全行为的命令。
- 每个提示模板都可以通过其模板名称调用。
- 启用技能命令后，技能可以通过 `/skill:name` 使用。

添加或更改自动发现的命令资源后，请使用 `/reload`。其加载与命名规则见[扩展](extensions.md)、[提示模板](prompt-templates.md)和[技能](skills.md)。
